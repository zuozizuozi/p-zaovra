# Zaovra Home Page Topology

## Product truth

- The page presents Zaovra as a local-first desktop AI coding workspace.
- BYOK is a primary product path. It does not require a Zaovra account and does not consume Zaovra-managed inference.
- An active Zaovra subscription is a second, managed-model access path. Do not name it Zen or invent plan names, prices, quotas, trials, or free models.
- WorkGraph is real code under active implementation. It may appear only as a clearly labelled preview until it is merged, built, and release-verified.
- Do not claim that code never leaves the device, that every model works with WorkGraph, or that remote workers are production-grade distributed infrastructure.

## Page order

1. Product-specific header
   - Wordmark, Product, BYOK, WorkGraph preview, Docs, GitHub, Download.
   - No Zen, Go, Data, login, or “free” CTA on the home page.
2. Hero: desktop coding workspace
   - Concise product promise and two CTAs.
   - A single product stage based on the real desktop session, review, terminal, context, and permission surfaces.
3. Workflow strip
   - Explore → Plan → Execute → Review.
   - This is explanatory, not a fake live progress component.
4. Desktop workbench details
   - Sessions, file review, terminal, LSP, permissions, multi-workspace.
5. BYOK
   - Provider connection panel with user-managed credentials and custom/local OpenAI-compatible endpoints.
   - Separate, smaller managed-subscription alternative.
6. WorkGraph preview
   - Goal, Task, Attempt, Evidence, Repair, Pause/Resume/Replan.
   - Explicit “Preview / in development” label. Remote workers are omitted from primary copy.
7. Local-first and open source
   - Open source, own server connection, BYOK, workspace grounding.
8. Model access comparison
   - BYOK versus active Zaovra subscription. No pricing claims.
9. Focused FAQ
   - Accounts, BYOK, local compatible endpoints, subscription boundary, WorkGraph preview status.
10. Download CTA and existing global legal/footer links.

## Responsive topology

- Desktop ≥ 1100px: 12-column content grid, two-column hero, product panels fill the right 7 columns.
- Tablet 720–1099px: stacked copy and product stage, two-column cards where space permits.
- Mobile < 720px: single column, horizontal navigation links collapse, product stage remains readable without horizontal page scrolling.
