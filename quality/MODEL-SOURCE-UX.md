# 对话入口与模型来源收敛

本轮按用户确认的方案修改桌面新界面，并在根 AGENTS.md 记录：后续桌面交互优先对标 Codex，入口与实际能力一致。

## 交付行为

- 加号仅保留“添加文件”；文件选择、拖拽和粘贴附件继续使用原有处理链路。移除该菜单里的快捷指令、引用上下文和终端命令入口。
- 模型选择统一为“自有 Key / 官方服务”。快捷键与点击打开同一个选择器，支持搜索、键盘切换来源、选择、关闭与焦点恢复。
- 自有 Key 仅列明确配置的模型。已有默认模型仍算明确配置；空白允许列表会禁用全部模型。尚未配置时提供配置引导，配置面板不混入官方池入口。
- 标准 Key 连接时保存模型发现结果为允许列表；自定义服务保存用户选择/填写的模型允许列表。不会把整个供应商预设目录当作用户拥有的模型权限。
- 官方模型保留 integrationID 来源，按服务返回的池配置启用，并遵守允许/禁止列表。官方供应商使用独立 ID，避免覆盖用户直连供应商。
- 输入框显示模型来源。显式选择失效时不自动切换到其他模型或付费来源。
- 切换来源标签本身不切换当前模型；选中具体模型才生效。关闭配置面板保留对话草稿。

## 验证

- app-ui、session-ui、core、desktop-app 包类型检查通过。
- app-ui 相关测试 16 项通过；官方供应商真实本地 HTTP 服务测试等 8 项通过。
- 生产前端回归 3 项通过：导航，以及未配置/已配置两种状态的加号、模型来源、配置返回、键盘操作和草稿保留。
- 对已配置与空状态截图做了目视检查，没有发现菜单溢出、错位、边框断层。
- 导航基线 214 ms；最终测量 246 ms。另一次三轮测量为 261 / 245 / 230 ms。样本有限，不将其声明为性能无回退。
- Electron 开发产物构建通过；没有制作安装包，也没有重启用户正在使用的应用。

## 已知接入边界

官方登录、充值和实时余额仍沿用此前约定的官方服务接入范围。本轮移除了用模型单价推断用户已充值的界面分流，没有模拟账户余额。官方列表依赖服务返回的实际池配置；没有可用名单时显示明确空状态。上线时官方服务须按账户权益返回可用模型，并在执行端校验余额。

“已配置”不等于每一次模型调用都成功；供应商鉴权、额度和临时故障仍由实际请求返回处理。没有使用用户真实 Key 进行付费模型调用。

使用根目录“启动造物.bat”启动当前源码后，可按以上步骤人工验收。已打开的旧桌面窗口需由用户重新启动才能加载完整的新构建。
