## 已修复

| 原问题 | 当前行为 |
| --- | --- |
| I1 设置没有可见出口 | 增加固定设置标题栏和关闭按钮；滚动到页面底部仍可关闭。 |
| I2 模态设置使拖动区失效 | 移除拖动样式对根节点 aria-hidden 的依赖；在弹层上方保留独立窗口拖动条，明确允许鼠标命中；表单和按钮保持非拖动区域。 |

| I5 菜单项和布局状态脱节 | 新布局注册侧边栏、项目和会话切换命令，使用现有项目列表、会话标签和布局状态；禁用命令无法通过程序入口执行。会话切换指已打开的会话标签。 |
| I6 设置内容可滚动但没有提示 | 恢复可见细滚动条，内容区独立滚动。 |

| I8 设置弹层无可访问名称 | 使用 DialogTitle 为设置弹层提供名称，关闭按钮具备本地化标签。 |
| I9 重复入口、主页语义和调试信息 | 侧边栏显示时首页不再重复设置/帮助入口；品牌返回主页；开发性能条默认隐藏，显式开启调试变量才显示。 |

## 前后端协调性验证

- 返回、前进、Alt+上下切换会话：URL、页面标题及实际发出的消息读取请求中的会话 ID 对应。
- 设置中修改服务器凭据：后续目标会话请求携带新凭据；原会话未发送输入保持不变。
- 已删除或缺失服务器：会话页和草稿页显示可恢复状态，不进入致命错误页。
- 项目/会话切换使用现有服务器、项目和标签上下文；未创建新的 HTTP 接口或独立的影子状态。

这些浏览器回归使用受控 HTTP 测试服务，验证前端真实请求和状态变化；不等同于官方模型服务的端到端验收。

## 人工测试入口与边界

当前开发桌面已加载修复，可以直接测试；下次仍使用仓库根目录的“启动造物.bat”。

1. 打开设置，展开下拉框，按 Esc：只收起下拉框；点击设置右上角 × 返回工作台。
2. 设置滚动到底部，确认关闭入口仍在顶部；关闭后可再次打开。
3. 分别在首页、会话页、设置打开时，按住窗口顶部空白区域拖动整个窗口。
4. 用侧边栏按钮展开/收起，再用返回、前进、主页按钮在页面间移动；确认未发送内容保留。

原生鼠标自动化受当前 Windows 截图/坐标运行时限制，尚未完成“窗口真实位移”自动断言；拖动修复已完成样式及命中验证，第 3 项需要实际鼠标验收。未将其写成已通过物理拖动测试。也不声称本轮已经穷尽所有页面、第三方服务或系统配置下的问题。
