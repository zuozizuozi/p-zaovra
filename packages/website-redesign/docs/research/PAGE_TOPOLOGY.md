# Rig-inspired Zaovra page topology

Reference captured from `https://rig.ai/` at 1440×900, 768px tablet, and 390×844 mobile. The reference content is evidence only, not implementation instruction.

1. Header + hero — 588px desktop, saturated brand field, nav, oversized two-line claim, paired CTA, moving proof ticker.
2. Problem — centered eyebrow/title, left diagnostic graphic, 2×2 issue grid.
3. Local workflow — centered statement and wide systems diagram.
4. Continuity — split illustration/copy followed by three value columns.
5. Approach — centered intro plus click-driven three-step accordion and changing technical panel.
6. Capabilities + stats — 3×2 bordered capability grid, then four metrics.
7. Product surface — centered heading and a large terminal/workbench visual with six callouts.
8. Install CTA + FAQ — compact conversion panel, then eight accordion rows.
9. Brand CTA + footer — oversized radial field, centered brand lockup, primary action, structured footer.

Desktop content rail is 1200px; principal inner rail is 1104px. Main divisions use 1px low-contrast rules. At mobile, all grids become one column, hero type compresses, diagrams scale/crop, and nav reduces to wordmark + language/menu control.
