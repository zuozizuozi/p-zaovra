ชุดโครงการชุมชนที่สร้างขึ้นบน Zaovra

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Zaovra ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-zaovra](https://github.com/awesome-zaovra/awesome-zaovra) และ [zaovra.cafe](https://zaovra.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
